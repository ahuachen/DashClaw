- `$schema` enables IDE autocompletion for vercel.json fields
- `framework: "nextjs"` tells Vercel to use the Next.js build adapter
- `buildCommand: "npm run db:push && next build"` chains Drizzle schema push (idempotent on existing schema — confirmed safe without `--force` flag) before the Next.js build step. This runs at build time in a non-serverless context, avoiding timeout issues.
- First cron: `/api/cron/signals` every 5 minutes (anomaly detection signals)
- Second cron: `/api/cron/integration-health` every 6 hours (credential validation)
- Both cron routes already exist in the codebase — this only registers them with Vercel's scheduler
