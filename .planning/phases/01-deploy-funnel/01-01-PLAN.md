Steps for the developer:
1. Ensure you have a Neon database with the existing DashClaw schema already applied (from a previous `db:push` or migration).
2. Run `npm run db:push` in a terminal. It should report no changes needed and exit 0.

4. To simulate non-TTY (Vercel build context), run: `echo "" | npm run db:push` or `npm run db:push < /dev/null`

If `db:push` hangs or prompts for input in non-TTY mode, we need to switch to a startup-time check instead of buildCommand (as noted in CONTEXT.md fallback).
