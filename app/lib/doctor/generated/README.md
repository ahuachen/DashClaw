# Generated doctor artifacts

This directory is **auto-generated by livingcode**. Do not edit by hand.

Regenerate with:

```bash
npm run livingcode:refresh
```

The pre-commit hook regenerates these files automatically whenever you stage
changes to routes, library code, or the schema. If you see a diff here that
you didn't introduce manually, that's expected — commit it along with your
source changes so the doctor stays in sync.

  Read by `app/lib/doctor/shape.mjs`.
- `last-snapshot.json` — the baseline the drift check compares against. Also
  refreshed by `npm run livingcode:refresh`.
- `checks-from-shape.mjs` — auto-generated doctor checks, one per table and
  required env var. Imported by `app/lib/doctor/engine.mjs` under the `shape`
  category.
